# Claude Cream

A theme for the Claude desktop and mobile apps: cream paper in light mode, warm charcoal in dark mode, with terracotta accents, green, amber and purple for status, and tuned git colors.

## Install

At the prompt of a terminal session:

```
/plugin install claude-cream --marketplace rpplavr/claude-cream
```

From a shell:

```bash
claude plugin install claude-cream --marketplace rpplavr/claude-cream
```

Answer `y` to add the marketplace, then pick a scope (user is first).

In the desktop app, where `/plugin` does not run: click + next to the prompt box, then Plugins, Add marketplace with `rpplavr/claude-cream`, then Add plugin.

## Use

- `/cream` toggles between Claude Cream and the default theme
- `/cream on` / `/cream off` set it explicitly

The choice is remembered across sessions. Light or dark follows the app's own appearance setting.

The terminal and editors don't draw themes; this changes the desktop and mobile apps.
